# CloseCrab 安装指南（大白话版）

CloseCrab 是一个命令行工具，装好之后在终端里敲 `closecrab` 就能用。
下面按你的系统挑一段照做就行。

---

## 一句话总结

| 系统 | 最省事的装法 | 装完怎么用 |
|------|-------------|-----------|
| **Windows** | 双击安装包 `CloseCrab-Setup-x.x.x.exe` | 重开一个终端，敲 `closecrab` |
| **macOS** | 终端粘一行命令 | 敲 `closecrab` |
| **Linux / Ubuntu** | 终端粘一行命令 | 敲 `closecrab` |

装好第一次运行会自动生成配置文件，不用手动建。

---

## Windows

### 办法一：安装包（推荐，最简单）

1. 打开发布页：https://github.com/Blitzball996/CloseCrab-Unified/releases/latest
2. 下载 `CloseCrab-Setup-0.4.4.exe`
3. 双击运行，一路“下一步”。**“Add to PATH”那个勾默认是打上的，别取消**——它就是让你能在任何终端直接敲 `closecrab` 的关键。
4. 装完 **重新开一个** PowerShell 或 CMD 窗口（老窗口不认新 PATH），敲：
   ```
   closecrab
   ```

### 办法二：一行命令装（不想点安装向导就用这个）

打开 PowerShell，粘这一行回车：
```powershell
irm https://raw.githubusercontent.com/Blitzball996/CloseCrab-Unified/main/scripts/install-windows.ps1 | iex
```
它会把程序下载到 `%LOCALAPPDATA%\CloseCrab`，自动加进 PATH。装完当前窗口就能直接敲 `closecrab`。

### 办法三：手动解压（前两个都不想用）

1. 下载 `CloseCrab-Windows-x64.zip`，解压到比如 `C:\Tools\CloseCrab`
2. 把这个目录加进 PATH（PowerShell 里跑一次）：
   ```powershell
   [Environment]::SetEnvironmentVariable("Path",
     [Environment]::GetEnvironmentVariable("Path","User") + ";C:\Tools\CloseCrab", "User")
   ```
3. 重开终端，敲 `closecrab`

## macOS

打开“终端”，粘这一行回车：
```bash
curl -fsSL https://raw.githubusercontent.com/Blitzball996/CloseCrab-Unified/main/scripts/install-macos.sh | bash
```

这行命令会自动做完这些事：
- 下载适配你芯片的版本（M 系列和 Intel 都支持，一个包通用）
- 装到 `~/.local/bin/closecrab`
- 去掉 macOS 的“未知开发者”隔离标记（省得被拦）
- 把 `~/.local/bin` 加进 PATH

装完敲：
```bash
closecrab
```

> 如果提示 `closecrab: command not found`，就**关掉终端重开一个**，或者手动跑一下：
> ```bash
> export PATH="$HOME/.local/bin:$PATH"
> ```

也可以下载 `.pkg` 安装包双击装，效果一样（装到 `/usr/local/bin`）。

## Linux / Ubuntu 24.04

打开终端，粘这一行回车：
```bash
curl -fsSL https://raw.githubusercontent.com/Blitzball996/CloseCrab-Unified/main/scripts/install-linux.sh | bash
```

这行命令会自动：
- 认出你是 x86_64 还是 arm64（云服务器、树莓派、ARM 机器都支持），下对应的包
- 装到 `~/.local/bin/closecrab`（不需要 sudo；写不进去才会退回 `/usr/local/bin` 要一次密码）
- 把 `~/.local/bin` 加进 PATH

装完敲：
```bash
closecrab
```

> 提示 `command not found` 的话，重开终端，或跑 `export PATH="$HOME/.local/bin:$PATH"`。

没装 `curl` 的话，脚本会自动用 `wget`；两个都没有就先 `sudo apt install curl`。

## 装完之后：换模型 / 换服务商

不用再去手动翻配置文件了，程序里直接切。

### 换模型
```
/model                     # 看当前用的什么模型，以及上游有哪些可选
/model claude-sonnet-5     # 换成这个（立刻生效，同时存进配置文件）
```
或者启动前一步到位：
```bash
closecrab --set-model claude-sonnet-5
```

### 一键换整套（网址 + 密钥 + 模型）
先在配置文件 `config.yaml` 里把常用的几套写好：
```yaml
profiles:
  一口练:
    url: "https://yikoulian.cc/"
    api_key: ""
    model: "claude-opus-4-7"
  官方:
    url: "https://api.anthropic.com/"
    api_key: "sk-ant-..."
    model: "claude-opus-4-8"
```
然后在程序里：
```
/profile          # 列出你定义的所有套餐
/profile 官方     # 一键切过去，三样一起换，立刻生效
```

配置文件在哪：
- **Windows**：程序目录下的 `config\config.yaml`
- **macOS / Linux**：`~/.crab/config.yaml`

## 升级到新版

```bash
closecrab --update
```
自动检查 GitHub 上有没有新版，有就下载替换，重启后生效。
（也可以在程序里敲 `/update`。）

## 卸载

**macOS / Linux**：
```bash
curl -fsSL https://raw.githubusercontent.com/Blitzball996/CloseCrab-Unified/main/scripts/uninstall.sh | bash
```
想连配置数据一起删，加 `--purge`：
```bash
curl -fsSL .../uninstall.sh | bash -s -- --purge
```

**Windows**：控制面板里正常卸载，或跑程序目录里的 `uninstall.bat`。

## 常见问题

**Q：敲 `closecrab` 说找不到命令？**
A：十有八九是 PATH 没刷新。**关掉终端重新开一个**。还不行就按上面各系统的 `export PATH` / SetEnvironmentVariable 手动加一次。

**Q：Windows 装完双击没反应 / 缺 DLL？**
A：用安装包（办法一）而不是手动解压——安装包会把 `libcurl.dll`、`zlib1.dll` 这些运行库一起放好。

**Q：macOS 提示“无法打开，来自身份不明的开发者”？**
A：用上面那条一行命令装的话已经自动处理了。如果是手动下的，跑一次：
```bash
xattr -dr com.apple.quarantine ~/.local/bin/closecrab
```

**Q：换了模型/服务商没生效？**
A：`/model` 和 `/profile` 都是立刻生效并存盘的，不用重启。如果还是旧的，确认你改的是正在用的那个配置文件（路径见上面）。
